Adaptive probing

A better next question.

C2 flags parts of a submission. C3 cuts those parts out, finds the knowledge they use, and writes follow-up questions for the interviewer. Send the mock hand-off below and watch each step run. A flag starts a conversation; it does not make the decision.

What the labels on this page mean
Demo data
The code and the flags are made up for this demo. No real candidate.
Fake model
Answers come from a stub, not a real model. Shown when no real model is configured.
Cached result
Answers were recorded earlier from a real model and are replayed. Nothing is called now.
Unverified
A question's tests were not run. This is the default for every question.
Reference-checked
The model's own reference solution reproduced the model's own expected values in a sandbox. Both came from the same model, so this is not proof the question is right.
Advisory
The reviewer's opinion. It never approves anything.

02

Segment Extraction

Each flag becomes a complete piece of code, cut at function and statement boundaries. Touching flags are merged. A flag that cannot be used is rejected with a reason and never stops the task.

03

Knowledge, questions and checks

Pick a segment above, run the stages one by one, or run them all. Tags are evidence about the code, not about the candidate.

04

Why the reference check exists

A question that passed every static check but has a wrong expected value. The reference check catches it, and approval is disabled for it.
